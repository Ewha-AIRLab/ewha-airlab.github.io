[3D] Forward Kinematics — SCARA (RRPR)

SCARA robot with 4 joints: R(Rz, q₁) · R(Rz, q₂) · P(vertical, q₃) · R(Rz, q₄). Column height l₁ = 1.2 m, arm 1 l₂ = 1.0 m, arm 2 l₃ = 0.8 m, tool offset l₄ = 0.3 m. Set joint values to compute the end-effector pose.

Joint Values
q1 — base rotation R 0°
q2 — elbow rotation R 30°
q3 — vertical lift P 0.00 m
q4 — wrist rotation R 0°
End-Effector Pose
(xee, yee, zee) —
FK Equations
Transforms
T01 = Rz(180+q₁) · Trans(0, 0, l₁)
T12 = Trans(l₂, 0, 0) · Rz(q₂)
T23 = Trans(l₃, 0, 0)  ← fixed link
T34 = Rz(90+q₄) · Trans(0, 0, −l₄+q₃)
End-effector position
pee = T01·T12·T23·T34 · [0,0,0,1]T
= Tworld,ee · [0,0,0,1]T
Transformation Matrices
T01 = Rz(180+q1) · Trans(0,0,l1)
T12 = Trans(l2,0,0) · Rz(q2)
T23 = Trans(l3,0,0) — fixed
T34 = Rz(90+q4) · Trans(0,0,−l4+q3)
Tworld,ee = T01·T12·T23·T34
