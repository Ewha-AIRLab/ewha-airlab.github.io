3D A* Motion Planning — 3-Link Robot Arm

A* search finds a collision-free path in a 3-dimensional configuration space (θ₁, θ₂, θ₃). Each grid node is a joint-angle triple; collision is tested by checking whether any link segment intersects an obstacle box. The visited nodes and solution path are shown directly in C-space, while the arm animates in the 3D workspace.
