Minimum Distance Between BST Nodes

Problem 1 · Topic: Binary Search Tree · Source: LeetCode 783

문제 설명

이진 탐색 트리(BST)의 루트가 주어졌을 때, 서로 다른 두 노드 값 차이의 최솟값을 반환하세요.

예시

Example 1

Input: root = [4, 2, 6, 1, 3] Output: 1

Example 2

Input: root = [1, 0, 48, None, None, 12, 49] Output: 1

제약 조건

  • 트리의 노드 수는 [2, 100] 범위입니다.
  • 0 <= Node.val <= 105

힌트

BST에서 inorder traversal은 노드 값을 정렬된 순서로 방문합니다. inorder()를 먼저 구현해 정렬된 리스트를 만든 뒤, 인접한 두 값의 차이 중 최솟값을 반환하세요.

제공되는 클래스

class TreeNode(object): def __init__(self, val=0, left=None, right=None): self.val = val self.left = left self.right = right

Minimum Amount of Time to Fill Cups

Problem 2 · Topic: Heap (Priority Queue) · Source: LeetCode 2594

문제 설명

정수 길이 3의 배열 amount가 주어집니다. amount[0]은 cold water cup의 수, amount[1]은 warm, amount[2]는 hot입니다.

매 초마다 다음 중 하나를 할 수 있습니다:

  • 서로 다른 두 종류의 cup을 각각 하나씩 채우기 (총 2개)
  • 한 종류의 cup을 하나 채우기 (총 1개)

모든 cup을 채우는 데 필요한 최소 시간(초)을 반환하세요.

예시

Example 1

Input: amount = [1, 4, 2] Output: 4 Explanation: One way to fill up the cups is: Second 1: Fill up a cold cup and a warm cup. Second 2: Fill up a warm cup and a hot cup. Second 3: Fill up a warm cup and a hot cup. Second 4: Fill up a warm cup. It can be proven that 4 is the minimum number of seconds needed.

Example 2

Input: amount = [5, 4, 4] Output: 7 Explanation: One way to fill up the cups is: Second 1: Fill up a cold cup, and a hot cup. Second 2: Fill up a cold cup, and a warm cup. Second 3: Fill up a cold cup, and a warm cup. Second 4: Fill up a warm cup, and a hot cup. Second 5: Fill up a cold cup, and a hot cup. Second 6: Fill up a cold cup, and a warm cup. Second 7: Fill up a hot cup.

Example 3

Input: amount = [5, 0, 0] Output: 5 Explanation: Every second, we fill up a cold cup.

제약 조건

  • amount.length == 3
  • 0 <= amount[i] <= 100

힌트

Python의 heapq 모듈 built-in 함수를 활용하세요.

  • heapq.heapify(list)
  • heapq.heappush(heap, item)
  • heapq.heappop(heap)

Red-Black Tree Insert

Problem 3 · Topic: Red-Black Tree · Source: 강의자료 슬라이드

문제 설명

Red-Black Tree의 insert(key) 메서드를 구현하세요. 여러 개의 key를 순서대로 삽입한 뒤 inorder()를 호출하면 정렬된 리스트를 반환해야 합니다.

_left_rotate, _right_rotate, _insert_fixup은 이미 구현되어 있습니다.

예시

Example 1

tree.insert(10) tree.insert(5) tree.insert(20) tree.insert(1) tree.insert(15) tree.inorder() -> [1, 5, 10, 15, 20]

Example 2

tree.insert(1) tree.insert(2) tree.insert(3) tree.insert(4) tree.insert(5) tree.inorder() -> [1, 2, 3, 4, 5] # BST라면 unbalanced되지만 RB-Tree는 fixup으로 균형 유지

제공되는 클래스 (이미 작성됨)

class RBNode: def __init__(self, val=None, color="RED"): self.val = val self.color = color # "RED" or "BLACK" self.left = None self.right = None self.parent = None class RedBlackTree: def __init__(self): self.NIL = RBNode(None, "BLACK") self.NIL.left = self.NIL self.NIL.right = self.NIL self.NIL.parent = self.NIL self.root = self.NIL # 제공 메서드 (직접 호출 가능): # self._left_rotate(node) # self._right_rotate(node) # self._insert_fixup(node)
