문제 설명

Example 1

Input: root = [], targetSum = 0 Output: False

Matrix Chain Multiplication

Problem 3 · Topic: Dynamic Programming

문제 설명

길이 n+1인 정수 배열 p가 주어집니다. 이 배열은 n개의 행렬 A₁, A₂, …, Aₙ의 크기를 나타냅니다. 행렬 Aᵢ의 크기는 p[i-1] × p[i]입니다.

A₁ · A₂ · … · Aₙ을 계산하는 데 필요한 스칼라 곱셈의 최소 횟수를 반환하세요.

예시

Example 1

Input: p = [10, 30, 5, 60] Output: 4500 Explanation: A₁(10×30), A₂(30×5), A₃(5×60) (A₁·A₂)·A₃ = 10·30·5 + 10·5·60 = 1500 + 3000 = 4500 ← 최적 A₁·(A₂·A₃) = 30·5·60 + 10·30·60 = 9000 + 18000 = 27000

Example 2

Input: p = [1, 2, 3] Output: 6 Explanation: A₁(1×2), A₂(2×3) — 순서가 하나뿐: 1·2·3 = 6

Example 3

Input: p = [30, 35, 15, 5, 10, 20, 25] Output: 15125 Explanation: 6개 행렬 (교재 예제)

제약 조건

  • 2 <= p.length <= 500
  • 1 <= p[i] <= 1000
